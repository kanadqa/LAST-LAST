# Финансы (доходы/расходы + капитал)

Единое офлайн-приложение с боковым меню и переключаемыми экранами. Данные сохраняются в IndexedDB браузера, есть диаграммы, управление категориями, а также полноценный модуль «Капитал» (активы/долги/цели/снапшоты).

## Что нового

- Навигация по разделам: «Обзор», «Операции», «Категории», «Отчеты», «Капитал».
- Три варианта интерфейса (Комфорт/Баланс/Компакт) — выбираются в боковом меню.
- Единая форма добавления: категория и подкатегория в одном действии.
- Полноценное управление категориями: переименование, удаление, перенос подкатегорий.
- Добавлены круговые диаграммы доходов и расходов и график динамики по дням.
- Категории и подкатегории можно перетаскивать между карточками мышью.
- Кнопка «Отменить» возвращает последнее действие.
- Общий backup/restore JSON и отдельный импорт/экспорт для раздела «Капитал».

## Как пользоваться

1. Запустите локальный сервер и откройте `index.html` в браузере (см. ниже).
2. Перейдите в «Операции» и добавьте запись.
3. В разделе «Категории» добавляйте категории и подкатегории через один блок.
4. Перетаскивайте подкатегории в другие карточки.
5. Чтобы сделать подкатегорию отдельной категорией, перетащите ее в блок «Категории верхнего уровня».
6. Чтобы превратить категорию в подкатегорию, перетащите карточку категории в другую категорию.
7. В «Обзоре» смотрите диаграммы и график доходов/расходов по дням.
8. Нажмите «Экспорт CSV», чтобы сохранить операции для Excel/Google Sheets.
9. В «Капитале» добавляйте активы, долги и цели, делайте снапшоты, импортируйте/экспортируйте JSON.

## Категории и подкатегории

Категории и подкатегории задаются вручную в блоке «Категории». Тип категории определяет, в каком режиме операции она доступна (доходы или расходы).

## XLSX-альтернатива

Если вам удобнее работать именно в Excel, используйте файл `template.csv` и откройте его в Excel как CSV. Затем сохраните как `.xlsx` при необходимости.

## Импорт и экспорт

- **Экспорт CSV** — выгружает операции в UTF-8 CSV.
- **Backup JSON** — сохраняет весь слепок приложения (операции, категории, капитал, настройки).
- **Восстановить JSON** — восстанавливает backup с валидацией и миграцией.
- **Экспорт капитала (JSON)** — отдельная выгрузка только раздела «Капитал».

## Где хранятся данные

Все данные хранятся в IndexedDB (ключи `budget.transactions.v2`, `budget.categories.v3`, `budget.capital.v2`, `budget.view.active`, `budget.layout`, `budget.capital.assets.uiState`). При необходимости выполняется миграция из старых форматов.

## Фото и иконки активов

В модальном окне актива можно указать emoji-иконку или загрузить фото. Фото автоматически уменьшается до 96×96 и сохраняется в `avatarDataUrl` (dataURL). Если фото не задано, показывается emoji, а если emoji отсутствует — системная иконка по типу.

## Selftest режим

Для самопроверки откройте приложение с параметром `?selftest=1`. Пример:

```
http://localhost:8000/index.html?view=capital&selftest=1
```

Результаты тестов появятся в консоли и в небольшом блоке на странице.

## Запуск локального сервера

Если браузер блокирует доступ к локальному хранилищу при открытии файла напрямую, запустите простой сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.
